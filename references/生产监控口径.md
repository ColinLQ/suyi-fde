# 生产监控口径（会议规则版）—— build-production-report.py 的判定逻辑全文


> 📁 **路径约定（V1.6）**：本文件的 `out/`、`state/`、`data/raw/` 均指数据根目录（默认 `~/WorkBuddy/scm-collector-data/`，可用环境变量 SCM_DATA_HOME 覆盖）下的相对路径，非 skill 代码目录。
> 规则来源：2026-10-23 生产需求会议（老板 / 生产经理生产经理 / 衣者·多客对接人系统对接人 / 实施方）。
> 产出脚本：`scripts/build-production-report.py`（本文件是其唯一口径依据，改规则先改这里再改代码，并留痕）。
> 迁移性：所有参数集中在 `config/production-params.json`（可选，缺省用脚本内置默认值），换设备无需改代码。

## 数据链路（在任意设备上复现）

```
第0步  登录校验（SKILL.md 主流程，两系统任一未登录即硬停）
第1步  node scripts/fetch-endpoints.mjs --batch first --date <YYYY-MM-DD> \
         --only yizhe_production_list.jsonl,yizhe_cuted_records.jsonl,yizhe_material_store.jsonl,yizhe_factory_list.jsonl
第2步  python3 scripts/build-production-report.py --date <YYYY-MM-DD> [--slot am]
产出   out/生产监控日报_<日期>.xlsx（5 sheet：总览 / ①数量比对 / ②货期预警 / ③工厂负荷 / ④辅料物料；
       每个 sheet = 汇总 KPI(上) + 明细(中，整行按档位着色+表头筛选) + 口径说明(下)）
```

依赖：python3 + openpyxl；无任何机器特定路径（全部相对 skill 根目录解析）。

## 可配置参数（config/production-params.json 可覆盖）

| 参数键 | 默认 | 会议依据 |
| --- | --- | --- |
| qty_threshold | 0.01 | 老板："100件1件、400件就少4件，设卡"（1% 阈值） |
| qty_exempt | 2 | 正常损耗差≤2件豁免（调机/坯布头） |
| overdue_tolerance | 0 | 老板："裁了多少出多少…多出必有问题"（多出零容差） |
| lead_days | 7 | 老板："面料到工厂以后7天"（裁床开工+7天兜底） |
| near_days | 2 | 临期提醒窗口 |
| fac_over_red | 5 | 工厂逾期≥5单=红档（实施方分档建议，可调） |
| material_surplus_min | 50 | 主料剩余≥50单位列可复用（老板：剩余料是成本） |

## D-1 数量比对（裁床数 ↔ 出货数）

- **裁床数** = 裁床记录（`cuted_order_panel/record_list`）按 production_id 汇总 cuted_num；**出货数** = 生产单 `stock_out_num`。
- **比对范围** = 有裁床记录的生产单（"已开工"）；未开工单无比对基准，不进本模块（147 在产中约 124 已开工，随日期浮动）。
- **多出**：出货数 > 裁床数 即红，零容差 → 通知跟单 → 工厂书面解释 → 生产经理审批关闭，全程留痕，3 次未解释升级老板。
- **少出**：|差异率| > qty_threshold 且 |差异| > qty_exempt。
- **豁免**：差 ≤ qty_exempt 件记"正常损耗"（灰色，不预警）。
- **已知噪音**：约 50% 缺口的单（如 SK263991 两单各缺 50%）疑似分批出货未录全 —— 跟单先核对录入再追责工厂。

## D-2 货期预警

- **应完工日**：优先取生产单 `estimated_finish_time`；缺失按 **裁床开工日 + lead_days 兜底**。
- **逾期** = 应完工日 < 今日 且 出货数 < 计划数（已出足自动排除）。
- **临期** = 剩余 ≤ near_days 天。
- 正式版每 24 小时重复推送未关闭逾期项；本表为当日快照。
- 数据建议：无预计完工日的单（约 61/147）建议跟单补录。

## D-4 工厂负荷

- 在产单/计划件/已裁/已出 按工厂聚合；完成率 = 已出 ÷ 计划件；逾期单 = 该厂名下货期红档数。
- 分档：逾期 ≥ fac_over_red 单 = 红·重点关注；1~(N-1) 单 = 黄；0 = 绿。
- 排产规则（会议）：看负荷松紧排新单，避开红档工厂；产能参数衬衣 500 / 外套 300 / 统一卡点 400 件每天。
- **未启用**：4 天备货触发线（需工厂在手量字段，衣者列表接口未提供；后续可从生产单在手数聚合近似）。

## D-5 物料结存

- **结存** = 衣者物料库存 `gap` / `total_gap_num`（采购入库 − 生产领用）；负数 = 领用超采购（红：疑错账/损耗未录/流失，需盘点）。
- **可复用** = `material_type==1`（主料）且 total_gap_num ≥ material_surplus_min（黄：转设计评估复用）。
- **卡点 F4**：衣者物料库存"不勾对款号"（related_template_nos 大面积为空），负结存无法定位到款式 —— 需采购侧补录"物料入库必须挂款号+色号；整包采购备注结余"后才能逐款追责。

## 与既有链路的边界

- 本链路与经营日报（ingest→alert→report-daily）**相互独立**：经营日报管销售/库存/补货，本链路管生产过程（裁床/货期/产能/物料）。
- 触发词建议：「生产日报」「生产监控」「裁床出货对不上」「货期逾期」→ 走本链路；「跑销售日报」「经营日报」走原链路。
