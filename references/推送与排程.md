# 推送与排程（配企微推送/定时任务时读）

## 企微推送双通道（notify.mjs，V1.4起）

**通道A（默认）**：WorkBuddy 内置企微 —— `wecom-cli message aibot send` 发授权人，无需任何配置。
- 前置：`wecom-cli auth show --status` = authorized；机器人「消息」权限有效（过期时接口返回 help_message 带授权链接，需用户在企微「工作台-智能机器人」重新授权）
- 授权人ID获取：`wecom-cli identity whoami`，输出为非标准JSON（身份嵌在提示文本里），用正则 `授权真人用户身份[\s\S]{0,200}?ID[：:]\s*(wo[\w-]+)` 提取；机器人ID是 `aib` 前缀，**不能**用作 chat_id
- 推送内容：①企微版日报总览 ②预警专项（⛔/🔴前12款表格）
- 发送成功判定：退出码0 且 stdout 无 `"errcode":N(N≥1)`

**通道B（可选）**：企微群机器人 webhook —— `config/wecom-webhook.local.json`：
```json
{ "groups": { "default": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx", "销售": "..." } }
```
映射：企微版→default；研发/生产/销售/财务/仓库分版→同名group（缺省回落default）。未配置自动跳过。

## 定时批次（由 WorkBuddy 定时任务唤起，Skill内无定时器）

| 批次 | 时刻 | tier 范围 | 目标 |
|---|---|---|---|
| 早间 | 08:30 | poll + morning + increment（昨日窗口） | 日报推送，09:00前送达；库存=昨日晚快照 |
| 午间（可选） | 12:30 | detail 中在产类 | 当日中段进度 |
| 晚间 | 18:30 | 全部（当日窗口+snapshot+detail） | 全量库存快照+每日对账 |
| 预警轮询 | 每小时 | 仅 poll | 预警计算，命中即推 |
| 周一 | 07:00 | weekly + 样板全量回捞 | 维度刷新、款号映射基础（含 duoke_customers 客户数据） |
| 部署首跑 | — | 全部（含 onetime） | 阈值/配置落档 |

tier 含义：poll=轮询+早晚 ｜ morning=早间轻数据 ｜ increment=早采昨日窗/晚采当日窗 ｜ snapshot=晚间全量快照（早间不采，复用晚快照） ｜ detail=晚间明细 ｜ weekly=周一 ｜ onetime=首跑。

**速度参考**：早间≈11请求3-4秒；晚间全量≈50-70请求8-15秒；浏览器UI兜底≈15秒/页（仅故障）。

**建自动化提示词模板**（WorkBuddy定时任务）：
- 早报：`@skill:scm-collector 发日报`（08:30，工作日）
- 晚快照：`@skill:scm-collector 跑晚间批次`（18:30）
- 预警轮询：`@skill:scm-collector 跑预警轮询`（每小时）
